Create `src/lib/utils/hash.ts` — salted hash utility for IP and user agent:

```typescript
import { createHash } from 'crypto'

export function saltedHash(value: string): string {
  const salt = process.env.HASH_SALT
  if (!salt) throw new Error('HASH_SALT environment variable is required')
  return createHash('sha256').update(salt + value).digest('hex')
}

export function hashIp(ip: string | null): string | null {
  if (!ip) return null
  return saltedHash(ip)
}

export function hashUserAgent(ua: string | null): string | null {
  if (!ua) return null
  return saltedHash(ua)
}
```

Create `src/lib/utils/slug.ts` — random slug generation:

```typescript
const SLUG_CHARS = 'abcdefghijklmnopqrstuvwxyz0123456789'
const DEFAULT_LENGTH = 8

export function generateRandomSlug(length: number = DEFAULT_LENGTH): string {
  let result = ''
  const crypto = globalThis.crypto || require('crypto')
  const randomValues = new Uint8Array(length)
  crypto.getRandomValues(randomValues)
  for (let i = 0; i < length; i++) {
    result += SLUG_CHARS[randomValues[i] % SLUG_CHARS.length]
  }
  return result
}
```

Create all 8 API route handlers. Each route should:
1. Import and use `createAdminClient()` for database operations
2. Verify the `rp_session` cookie (except POST /sessions which creates it)
3. Return proper HTTP status codes
4. Use Zod schemas for input validation
5. Handle errors with structured JSON responses

**Route 1: POST /api/public/sessions** (`src/app/api/public/sessions/route.ts`)
- Body: `{ slug: string }`
- Creates session, sets `rp_session` cookie, fires QR_SCANNED + LANDING_VIEWED events
- Hashes IP and UA before storing
- Returns: `{ session_id, business_name, logo_url, primary_color, welcome_message, google_review_url_exists }`
- Status: 201 Created (new session) or 200 (existing active session from cookie)

**Route 2: PUT /api/public/sessions/[id]/answers/[question_key]** (`src/app/api/public/sessions/[id]/answers/[question_key]/route.ts`)
- Body: `{ value: int | string | string[] }` (validated by question type)
- Upserts answer, fires QUESTION_ANSWERED event
- Verifies session_id matches cookie
- Status: 200 OK

**Route 3: POST /api/public/sessions/[id]/start** (`src/app/api/public/sessions/[id]/start/route.ts`)
- No body
- Sets status to `in_progress`, fires QUIZ_STARTED (once per session, idempotent)
- Status: 200 OK

**Route 4: POST /api/public/sessions/[id]/submit** (`src/app/api/public/sessions/[id]/submit/route.ts`)
- No body (validates stored answers server-side)
- Validates Q1-Q3 present and int 1-5
- Sets status to `completed`, completed_at = now(), fires QUIZ_COMPLETED
- Idempotent: second submit returns 200 with stored result
- Status: 200 OK

**Route 5: POST /api/public/sessions/[id]/draft** (`src/app/api/public/sessions/[id]/draft/route.ts`)
- No body
- Stub: returns `{ original_text: "Draft generation coming in Phase 3", method: "stub" }`
- Idempotent: returns existing draft if present
- Status: 200 OK

**Route 6: PATCH /api/public/sessions/[id]/draft** (same file as Route 5, export PATCH)
- Body: `{ final_text: string }`
- Saves edited draft text
- Status: 200 OK

**Route 7: POST /api/public/sessions/[id]/events** (`src/app/api/public/sessions/[id]/events/route.ts`)
- Body: validated by `clientEventSchema`
- Inserts event with idempotency (ON CONFLICT DO NOTHING on session_id + client_event_id)
- Status: 201 Created or 200 (already exists)

**Route 8: POST /api/public/sessions/[id]/private-feedback** (`src/app/api/public/sessions/[id]/private-feedback/route.ts`)
- Body: validated by `privateFeedbackSchema`
- Inserts private feedback, fires PRIVATE_FEEDBACK_SUBMITTED event
- Status: 201 Created
